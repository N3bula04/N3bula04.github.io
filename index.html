Domain Brand Alert

Code private for nowPythonFastAPISQLiteBrand protection

What it is: a small local web app that watches a brand's domain for lookalikes. It generates typosquat, homoglyph, bit-flip, hyphen and TLD variants, then checks them against public DNS, certificate-transparency logs (crt.sh) and RDAP.

  • A watchlist with scheduled re-scans, allowlists and a "new since last scan" view, so only fresh findings surface.
  • Each finding has a severity, its source, a timestamp and a plain-language "why it matters".
  • A related-infrastructure panel shows where a lookalike overlaps with your own domain: the same IP, nameserver or certificate. It deliberately plays down overlaps that come from shared CDNs, bulk hosting or registrars.
  • A one-click evidence-pack ZIP, plus a demo mode with synthetic findings when public APIs are rate-limited.

Fictional example

watch: northwind-bakery.test
HIGH  northwlnd-bakery.test   homoglyph (i→l)   resolves · new cert in CT log
WARN  northwind-bakery-login.test  prefix/suffix     resolves · shares nameserver
INFO  nortwind-bakery.test    missing letter    registered · no DNS

Limits: results are heuristic signals with false positives, not attribution or takedown advice. Only monitor brands you're authorised to watch.

OSINT Pivot Tool

Code private for nowPythonCLICTIpytest + CI

What it is: a command-line tool that starts from one seed domain, collects public DNS, certificate-transparency and RDAP data, pivots one hop to related domains and IPs, and writes a Markdown report plus a CSV of links.

  • Every link cites its evidence and data source, and carries a High, Medium or Low confidence rating with a one-line reason.
  • Shared infrastructure such as CDNs, managed DNS, mail providers and cloud hosting is flagged and downgraded, so coincidences don't read as connections.
  • Sources that fail or return nothing are logged, so gaps are visible rather than hidden.
  • It never attributes activity to a named actor. It has an offline synthetic demo, a pytest suite and GitHub Actions CI.

osint-collectors

Code private for nowPython libraryDNSCT logsRDAP

What it is: a small shared library I pulled out of the two tools above so they use the same collectors for DNS records, crt.sh certificate entries and RDAP registration data.

  • It handles the unglamorous parts: a local JSON cache that never caches errors, backoff on server errors, and respecting HTTP 429 / Retry-After instead of hammering free services.
  • Registrable-domain logic uses the Public Suffix List's ICANN section, so shop.example.test and hosted subdomains are grouped correctly.
  • An offline replay mode blocks the network, so tests are reproducible.

Limits: a well-tested hobby library for small, occasional lookups by one person. It's not audited, not on PyPI and not meant for bulk scanning.

Open Source Person Brief

Code private for nowPythonFastAPIPublic sourcesEthics-first

What it is: a local app that helps me get oriented before meeting a speaker, author or business contact. It compiles a one-page brief from public, indexed sources such as Wikipedia, Wikidata, Open Library and Crossref.

  • Every brief records which sources returned usable data and whether the result is fully live, partial or a demo, so it never implies more certainty than it has.
  • Explicit confidence notes and a "gaps" section, because common names collide.
  • The demo mode uses a clearly fictional sample and is never attributed to the name that was searched.

How I frame its use: public indexed data only, for a legitimate purpose such as preparing for a meeting, ideally with the person's knowledge. There's no login bypass, no private-profile scraping, no breach data and no email hunting. It isn't for doxxing, harassment or screening decisions, and anything it finds should be verified before you act on it.

Trading Bot Lab

Code private for nowPythonpandasBacktestingResearch

What it is: a personal research lab for testing trading ideas honestly. It covers published strategies and my own ideas on US ETFs and gold, from daily charts down to 5-minute charts.

  • It's built to avoid fooling myself. Trades fill on the next bar with no lookahead, fees and slippage are included, costs are re-run at double, and years the rules were never tuned on are held back as a test.
  • Every strategy is compared against simply buying and holding.

The candid finding: most strategies, especially the fast intraday ones, did not beat buy-and-hold once realistic costs were included. Several had a small edge before costs that the costs wiped out. The most useful thing the lab taught me is how easily a backtest flatters an idea.

Not financial advice. It's research and paper trading only: no real money, no broker connection and no profit claims.
