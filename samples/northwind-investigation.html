  • It shares the brand's www address, 203.0.113.20, in the fictional DemoCDN range. It uses the same registrar, Example Registrar Ltd (fictional). Registrar overlap is always a weak signal.
  • The certificate names cover only the typo and www.nrthwind-bakery.test, with no login-style SANs. The fixture records an older registration on 2024-09-01.

Assessment

secure-northwind-bakery.test

High priority Medium confidence

I would check this lead first. A defensive or official registration, a vendor or staging host, a DNS account the brand used, or coincidental naming could explain the signals.

A live login page mimicking the brand, use of mail or MX that supports credential harvesting, or further non-shared infrastructure overlap would raise my confidence. A verified defensive registration, a shared or managed DNS service I had misread, parked or inactive login hosts, or no brand-mimicking content would lower it.

nrthwind-bakery.test

Medium priority Low confidence

I would log the resolving typo. Typo parking or traffic monetisation, an unrelated site using the same CDN, and a popular registrar used by unrelated domains could explain what I see.

A notable non-shared nameserver or certificate overlap, login-style certificate names, or brand-mimicking content would raise my confidence. Confirmed parking with no independent evidence would lower it further.

Next action

  • For secure-northwind-bakery.test, I would verify whether the overlapping nameserver and the login and account-verify certificate hostnames are in use, then capture that evidence. Impersonation remains unverified.
  • For nrthwind-bakery.test, I would log and monitor. I would need independent evidence before escalating beyond the shared CDN and registrar overlaps.

Gaps and limits

  • The tool uses public DNS, Certificate Transparency and RDAP only. This fictional run used offline fixtures. The tool does not fetch lookalike websites, so I have no site content to assess.
  • Shared CDN, hosting and registrar lists are incomplete.
  • Heuristic signals can produce false positives. Use them to guide verification. Only monitor brands you are authorised to watch.
